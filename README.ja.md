# MSI Affinity Utility (v9.0)

**MSI Affinity Utility** は、Windowsのハードウェア割り込み（IRQ）を高精度にチューニングするための最適化ツールです。  
クラシックな MSI（Message Signaled-based Interrupts）設定ツールの思想を受け継ぎつつ、**CPUコア・アフィニティ（コア割り当て）の詳細設定（Intel Pコア/Eコア自動判別対応）** や、安心の **ワンクリック復元（ロールバック `.reg` スクリプト自動生成）** 機能を独自に追加・拡張しています。

Guru3Dフォーラムの有志コミュニティおよび [Sathango/Msi-Utility-v3](https://github.com/Sathango/Msi-Utility-v3) にインスパイアされ、最新の **C# / .NET 8** で完全フルスクラッチ開発されました。

---

## 主な機能

1. **MSI モードの切替 & 割り込み優先度・リミット設定**
   - PCI / PCIe デバイス（GPU、LAN/Wi-Fi、NVMe、USBコントローラー等）の Message Signaled Interrupts (MSI) をワンクリックで有効化/無効化。
   - 割り込みリミットやプライオリティ（優先度）を柔軟に調整可能。

2. **CPU アフィニティ（コア割り当て）設定（ハイブリッドCPU完全対応）**
   - デバイスの割り込み処理を担当するCPUコアを指定し、ゲームやオーディオのフレーム落ち・スタッター・入力遅延（レイテンシ）を低減。
   - 最新の Intel 第12世代以降の **Pコア（高性能）/ Eコア（高効率）** を自動判別してラベル表示（`P0`, `P1`, `E12` など）。
   - N100 / N95 などの「全コアがEコア」のCPUも自動検出し、適切に `E0`, `E1` とナンバリング。

3. **安全なレジストリ即時適用 & 自動ロールバック（復元）機能**
   - **Apply Changes（変更適用）**: 管理者権限でレジストリへ即座に変更を書き込み。
   - **Rollback / Backup Script（復元スクリプト）**: 変更前のレジストリ状態を完全バックアップした `.reg` ファイルを自動生成。何かあってもダブルクリック1回で元の状態へ即座に復旧可能。

4. **モダンUI & 高DPI（Per-Monitor V2）対応**
   - 4KモニターやマルチDPI環境でも文字がぼやけない完全ベクター・スケーリング。
   - 適用モード（ブルー）と復元モード（アンバーオレンジ）で直感的に識別できるカラーハイライト付きコンソール搭載。

## 動作要件

- **対応OS**: Windows 10 (1809以降) / Windows 11 (64-bit)
- **必要なランタイム**: [.NET 8.0 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/8.0)
- **実行権限**: 管理者権限（デバイスの割り込みレジストリを操作するため必須）

## ソースコードからのビルド方法

.NET 8 SDK がインストールされている環境であれば、以下のコマンドで単一の実行ファイルをビルドできます。

### 必要な環境
- [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) (v8.0.400 以降)

### ビルドコマンド
```powershell
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o ./publish
```

ビルド完了後、`./publish/MsiAffinityUtility.exe` に単一実行ファイルが生成されます。

> [!CAUTION]
> **自己責任でご使用ください（At Your Own Risk）**  
> システムの基盤となるデバイス（ACPIコントローラー、チップセットブリッジ、システムタイマー等）の割り込み設定を変更すると、システムが不安定になったりブルースクリーン（BSOD）が発生する恐れがあります。  
> 本ツールの調整は、主に **GPU（グラフィックボード）** や **NIC（ネットワークカード）** に対して行うことを推奨します。

> [!NOTE]
> **セキュリティソフトの誤検知について**: 本ツールは低レベルなWindowsシステムレジストリを直接書き換えるため、一部のウイルス対策ソフトや Windows SmartScreen から警告が出る場合があります。透明性を担保するため、すべてのソースコードを本リポジトリで公開しています。
